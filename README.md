# AnalystLab-Africa-Internship
I am assuming the role of a Junior Project Manager. This Project will build an AI-powered churn prediction system that unifies customer data from Tarrose Retail's POS, e-commerce, and loyalty platforms to identify at-risk customers before they leave.

- Risk Register.
- Communication Plan.

## Week 3 Tasks
